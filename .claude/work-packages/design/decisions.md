# Design and scope decisions (made by the user)

One line per decision, with the date. Cards and design rounds must follow these.

| Date       | Topic               | Decision                                                                                                                                                                                                                                                                   |
| ---------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-03 | Keyboard shortcuts  | **Not on mobile.** The 22 desktop shortcuts are dropped. Where a key is today the _only_ way to do something (Escape to cancel or close), mobile needs a visible control.                                                                                                  |
| 2026-10-03 | tokens.css          | **Wire it in.** Move the tokens out of `src/style.css` into `src/styles/tokens.css`, import it, and end with **no duplicate**: one `:root` token block, in `tokens.css` only. Done by card WP0.D2.                                                                         |
| 2026-10-03 | Design round D0     | **Approved.** The design system is the artifact https://claude.ai/artifact/KNrkWbe3JnPVkLozKHPatS (four themes, desktop components from the code, proposed mobile layer `.mob-*`).                                                                                         |
| 2026-10-03 | Desktop CSS defects | **Fix them** (card WP1.C): select vs input height, icon offset in icon buttons, button heights. For button heights: cancel and danger buttons take the padding of action and confirm buttons.                                                                              |
| 2026-10-03 | UI verification     | Every design preview and UI change is **rendered and measured** in a browser before the user sees it (tops, heights, centres ±0.5px, text insets, overflow at 412 and 360px). Never judged from reading CSS.                                                               |
| 2026-10-04 | Button heights      | **Kept**, after the user saw before/after pictures of five real dialogs. A visual change is never decided from a description: show the screens, before and after.                                                                                                          |
| 2026-10-04 | D1 batch 1 feedback | Tab order: Ciel, **Galerie**, Cibles, Plans, Réglages. Use the desktop's meaning colours on mobile (yellow rating stars, etc.). The object sheet takes the height of its content. **No horizontally scrolling chip rows.** The Galerie screen has no title in its top bar. |

## Touch decisions for the mobile app (2026-10-03)

How each desktop interaction that needs a mouse or a keyboard works on the phone. All twelve were agreed by the user.

| #   | Desktop today                                          | Mobile                                                                                                                                                                                                                                                                                                         |
| --- | ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Object info on hover                                   | Tap an object: a bottom sheet opens low with name, type and altitude; drag it up for details and actions (add frame, add to plan, edit).                                                                                                                                                                       |
| 2   | Right-click clears the selection                       | Tap empty sky, or swipe the sheet down.                                                                                                                                                                                                                                                                        |
| 3   | Freehand region drawing by press-and-drag              | An explicit "draw region" mode: one finger draws, two fingers pan and zoom, Cancel and Done in the top bar.                                                                                                                                                                                                    |
| 4   | FOV frame handles of 9–11px                            | Tap a frame to select it, drag it with one finger. Rotation, pin, delete and mosaic size are in a sheet (slider, ±1° and ±5° buttons, row and column steppers).                                                                                                                                                |
| 5   | Manual photo placement by mouse                        | A full-screen placement mode: drag to move, pinch to scale, two-finger twist to rotate; fine sliders, mirror, Cancel and Validate in a bottom bar.                                                                                                                                                             |
| 6   | Three-point registration by clicking exact points      | **Kept in the first release** (user decision). Tap on the photo to place a point; two-finger pinch, move and zoom keep working. A bottom sheet lists the three points, each with a star-name field that searches the catalogue. A placed point can be dragged to adjust it, with a magnifier above the finger. |
| 7   | Gallery metadata panel opens on mouse movement         | An info button opens it as a bottom sheet.                                                                                                                                                                                                                                                                     |
| 8   | Gallery zoom buttons that auto-hide                    | Pinch and double-tap, plus a reset button shown only while zoomed.                                                                                                                                                                                                                                             |
| 9   | Drag-to-reorder draw order                             | A list with 48px drag handles.                                                                                                                                                                                                                                                                                 |
| 10  | Dragging 8px handles on observation windows            | Tap a window: a sheet with start and end time pickers.                                                                                                                                                                                                                                                         |
| 11  | Explanations and disabled reasons only in hover labels | Helper text under the control, and an "i" button that opens a sheet for longer explanations.                                                                                                                                                                                                                   |
| 12  | Custom date and time pickers                           | The phone's native pickers.                                                                                                                                                                                                                                                                                    |

Keyboard-only actions: every mode gets visible Cancel and Done buttons; label chips are committed with the keyboard's Done key or an Add button.
