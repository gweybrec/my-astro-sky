# MyAstroSky mobile design: factual inputs

Repo: C:\Workspace\MyAstroSky\MyAstroSky. All paths relative to it. "derived" = computed from padding/line-height, not measured in a browser. Facts only.

Global facts

- Stack: Vue 3 + Pinia + UnoCSS (preset-wind) + hand-written CSS (`src/style.css` 6381 lines, `src/styles/canvas.css` 509). Much of the UI is imperative DOM in `.ts` (gallery.ts, targets-view.ts, fov-overlay.ts, photo-overlay.ts, metadata-editor.ts, region-overlay.ts, dso-editor.ts), the rest Vue (`src/components/**`, mounted via Teleport into static divs in `index.html`).
- `index.html:5` viewport = `width=device-width, initial-scale=1.0`. No manifest link, no `touch-action` anywhere in src (grep), no `env(safe-area-*)`, no `pointer: coarse` / `hover: none` media query. `html, body { width:100%; height:100%; overflow:hidden }` (`style.css:401-409`). Body font = `var(--font-ui)`.
- Only two `@media` blocks exist (both `max-width: 768px`, quoted in section 7).
- Three views switched by `#view-tabs` (`index.html:17-21`, `stores/ui.ts:291-323`): `skymap` (canvas + side panel), `gallery`, `plans`. Side panel and its toggle are `display:none` outside `skymap` (`stores/ui.ts:317-320`).
- DOM layers (`index.html:16-57`): `#view-tabs`, `#map-container` (`#sky-canvas`, `#photo-layer`, `#overlay-canvas`), `#gallery-container`, `#plans-container`, `#side-panel`, `#toggle-panel`, `#fullscreen-viewer`, `#vue-modal-host`, `#loading-overlay`.

## 1. Design tokens (exact values)

### 1.0 Which file is live, which theme is default

- DEFAULT THEME = `cold-blue-v2` (`src/theme.ts:3-9`: `loadTheme()` returns `'cold-blue-v2'` when `localStorage['app-theme']` is absent/invalid). Settings label: "Modern cold (default)" (`en.ts:305`). Docs saying "warm is default" are stale.
- `applyTheme` (`theme.ts:11-15`) sets `document.documentElement.dataset.theme`: `''` for warm, else the theme name; stores to `localStorage['app-theme']`; fires `app-theme-changed` (canvas re-renders).
- WARM = bare `:root`. Live copy = `src/style.css:5-393`. `src/styles/tokens.css` is NOT imported anywhere (`main.ts:26-28` imports `virtual:uno.css`, `./style.css`, `./styles/canvas.css`). The two copies are identical except tokens.css:276-277 (`--hints-confirmed-bg: rgba(50, 150, 50, 0.1)`, `--hints-confirmed-text: #6c6`, unused) vs live style.css:276-277 (`--hints-active-border: rgba(200, 160, 50, 0.45)`, `--hints-active-bg: rgba(200, 160, 50, 0.06)`, used at style.css:1713-1714).
- Theme blocks: `[data-theme='cold-blue']` = `style.css:6160-6265`; `[data-theme='cold-blue-v2']` = `style.css:6271-6381`. Each overrides a subset; every other token inherits the warm value.
- Theme picker: Settings modal `<select>` (`SettingsModal.vue:20-27`), order v2, warm, cold-blue.
- Dead tokens: `--sky-bg-inner/outer`, `--constellation-line` are defined per theme but no TS reads them (grep). Sky look is theme-independent (section 3).
- UnoCSS theme (`uno.config.ts:13-102`) maps: colours bright/primary/secondary/label/dim/muted -> `--text-*`; app/deep/modal/panel/card/surface -> `--bg-*`; subtle -> `--border-subtle`; focus -> `--border-focus`; hint -> `--text-hint`; success/error -> `--status-*-bg`. Spacing keys 1..14 (+half steps) -> `--space-*`. Radii xs..pill. Font sizes micro/small/base/body/sub/title/head/large with line-heights 1.3/1.4/1.4/1.5/1.5/1.5/1.5/1.4. zIndex base/panel/sidebar/modal/gallery/tooltip. No fontFamily in the Uno theme.
